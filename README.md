# 🎓 졸업요건 RAG 챗봇

> 📚 **LLM 과목 과제**로 진행한 프로젝트입니다. (과제: RAG로 졸업요건 질의응답 챗봇 만들기 — ① 다면적졸업인증제 PDF 넣기 ② 안내받은 다른 문서도 넣기 ③ 내 활동·수강 과목으로 졸업 충족 여부 판정)

SW융합대학 **다면적졸업인증제** 기준 문서(PDF)를 근거로 답하는 질의응답 챗봇입니다.
내가 참여한 활동과 수강 과목을 입력하면 **졸업 기준을 충족하는지** 판정해 줍니다.

> **`index.html` 파일 하나**가 전부입니다. 서버·API 키·설치 없이 더블클릭하면 열리고, 파일(또는 정적 호스팅 링크)만 공유하면 다른 사람도 바로 쓸 수 있습니다.

## 기능

| 탭 | 기능 |
|---|---|
| 💬 질문하기 | "2022학번 컴퓨터소프트웨어공학과 졸업 총점은?" 같은 질문에 **근거 문서 조각(출처·페이지 포함)** 을 보여주며 답변 |
| ✅ 졸업 판정 | 대학공통 이수 체크 + 수강 과목 리스트 + 비교과 활동 입력 → 구간별 점수, 부족한 항목, 충족 여부 표시 |
| 📄 문서 | 탑재된 문서 목록 확인, **PDF/TXT/MD 추가 업로드**(내 브라우저에서만 사용) 또는 텍스트 붙여넣기 |

## 사용 방법

1. `index.html`을 브라우저로 엽니다.
2. 상단에서 **학과·학번**을 고릅니다(질문에 직접 적으면 그 값이 우선).
3. **질문하기**에서 예시 버튼을 누르거나 직접 질문합니다.
4. **졸업 판정**에서 ① 대학공통 항목 체크 ② 수강 과목 붙여넣기 ③ 비교과 활동 입력 → 결과가 즉시 갱신됩니다.

입력한 내용은 내 브라우저(localStorage)에만 저장되고 어디로도 전송되지 않습니다.

## 노트북으로 실습하기

`졸업요건_RAG_챗봇.ipynb`를 Jupyter/VS Code에서 열어 위에서부터 실행하세요. (프로젝트 폴더에서 `python3 build.py`를 먼저 한 번 실행)
지식베이스 로드 → BM25 검색 → 질의응답 → 졸업 판정 → 자동 검증 순서이며, 외부 라이브러리 없이 파이썬 표준 라이브러리만 씁니다.
내 정보는 "내 정보 입력" 셀의 `dept`, `year`, `my_courses`, `my_activities`만 바꾸면 됩니다.

## 어떻게 동작하나요 (RAG 구조)

```
PDF/문서 ──▶ 정리·분할(chunk, 학과/학번 메타데이터) ──▶ 색인(BM25)
                                                          │
질문 ──▶ 학과·학번 인식(필터) ──▶ 한글 2글자+단어 토큰화 ──▶ 검색 ──▶ 근거 chunk 표시
```

- **검색(Retrieval)**: 외부 임베딩/LLM 호출 없이 브라우저 안에서 BM25로 검색합니다. 질문에서 학과·학번을 읽어 맞는 chunk에 가중치를 주고, 다른 학과/학번 chunk는 걸러냅니다.
- **답변(Generation)**: 생성형 모델로 문장을 지어내지 않고 **문서 원문을 근거로 그대로 보여줍니다**(환각 방지). 점수 합계 질문은 문서에서 합계 값을 뽑아 한 줄 요약을 붙입니다.
- **졸업 판정**: 말로 추론하지 않고 `src/checker.js`의 기준표로 **직접 계산**합니다. 구간별(대학공통/교과/비교과 지정/비교과 미지정) 점수는 그 구간 요구 점수까지만 반영합니다.

## 폴더 구조

```
졸업요건_RAG_챗봇/
├── index.html            ← 결과물 (이것만 공유하면 됨, build.py 가 생성)
├── 졸업요건_RAG_챗봇.ipynb ← 파이썬 실습 노트북 (검색·질의응답·판정·검증)
├── build.py              ← knowledge + docs + src → index.html 빌드, 판정 규칙 JSON 내보내기
├── data/checker_rules.json ← 판정 규칙 (checker.js 에서 자동 생성, 노트북이 사용)
├── tools/export_rules.js ← 규칙 JSON 내보내기
├── knowledge/
│   └── 01_다면적졸업인증제.md   ← PDF를 학과·학번별로 정리한 지식베이스 (28 chunks)
├── docs/                 ← 원본 PDF 보관 / 추가 안내 문서 넣는 곳
├── tests/run_tests.js    ← 자동 검증 (검색 + 판정)
├── src/
│   ├── template.html  style.css
│   ├── engine.js         ← RAG 검색기 (BM25, 학과·학번 필터)
│   ├── checker.js        ← 졸업 판정 규칙
│   └── app.js            ← 화면 로직
└── README.md
```

## 다른 안내 문서 추가하기

**방법 A — 일회성(공유 불필요할 때):** `📄 문서` 탭에서 PDF/TXT/MD를 올리거나 텍스트를 붙여넣습니다. 새로고침하면 사라집니다.

**방법 B — 영구 반영(모든 사용자에게 공유):**

1. 문서를 `docs/`에 넣습니다. (`.pdf`, `.txt`, `.md`)
   - PDF는 페이지 단위로 자동 추출됩니다. 표가 많은 문서는 추출이 깨지므로, 가능하면 `knowledge/`에 같은 형식으로 손으로 정리하는 것이 가장 정확합니다.
   - PDF 추출에는 poppler가 필요합니다: `brew install poppler`
2. 빌드합니다.
   ```bash
   cd 졸업요건_RAG_챗봇
   python3 build.py
   ```
3. 새로 생긴 `index.html`을 다시 공유합니다.

`knowledge/*.md` 작성 형식:

```markdown
## 컴퓨터소프트웨어공학과 2027학번 졸업요건
- dept: cse            # cse | infosec | medit | aibd | iot | meta | common
- years: 2027-2027     # 입학 학번 범위
- page: 2

본문 (표는 "- 항목(점수)" 목록으로 풀어 쓰기)
```

## 공유하기

- **파일 그대로**: `index.html`을 메신저/메일/드라이브로 전달 → 받은 사람이 브라우저로 열기
- **링크로**: GitHub Pages, Netlify Drop(<https://app.netlify.com/drop>) 등에 `index.html`을 올리면 URL로 공유됩니다.
  PDF 업로드 기능만 인터넷(pdf.js CDN)이 필요하고, 나머지는 오프라인에서도 동작합니다.

## 테스트

```bash
python3 build.py          # index.html 생성
node tests/run_tests.js   # 질문 23개 + 판정 로직 + 6개 학과 21개 기준표 전수 검증 (현재 95/95 통과)
```

문서나 규칙을 바꿀 때마다 다시 돌려 보세요. `tests/run_tests.js`의 `QA` 배열에 `[질문, 프로필, 기대 문서 제목]`을 추가하면 케이스를 늘릴 수 있습니다.

## 개선 내역 (v1.1)

첫 검증(질문 16개 중 12개 통과)에서 발견한 문제를 고쳤습니다.

| 문제 | 수정 |
|---|---|
| "필요 점수", "기준 점수"로 물으면 합계 문서를 못 찾음 | 점수 관련 동의어를 "합계"로 통일하고, 합계 요약 문장도 같은 표현에서 동작 |
| "상담 어디로 가요?"에 학과 졸업요건이 나옴 | 어디·문의·위치·신청 류 질문은 공통 안내 문서에 가중치 2배, 문의처 문서에 검색 키워드 보강 |
| 범위 밖 질문("장학금 신청 기간")에 엉뚱한 답을 냄 | 질문의 핵심 단어 1/3 이상이 근거 문서에 있어야 답하도록 함(coverage). 아니면 "찾지 못했다"고 답변 |
| 학번 없이 다른 학과를 물으면 임의의 학번 표를 보여줌 | 내 학번을 다른 학과에 억지로 적용하지 않고, "학번을 함께 적으면 그 학번 기준만 보여드려요" 안내 표시 |
| 과목명 "캡스톤디자인Ⅱ"(로마숫자)를 인식 못함 | 판정 시 Ⅰ~Ⅳ를 1~4로 변환 |
| 군더더기 단어("가요", "알려줘" 등)가 검색을 흐림 | 불용어 제거 |
| 검증이 수동이었음 | `tests/run_tests.js` 자동 테스트 추가 |

## 지원 범위와 한계

- **질문하기**: PDF에 있는 6개 학과(컴퓨터소프트웨어공학, 정보보호, 의료IT공학, AI·빅데이터, 사물인터넷, 메타버스&게임)와 대학공통 필수 기준을 답합니다. 문서에 없는 내용은 "찾지 못했다"고 답합니다.
- **졸업 판정**: PDF에 기준표가 있는 **6개 학과 전체**(21개 학번 구간)를 지원합니다. 기준표가 없는 학번(예: 사물인터넷학과 2016학번)은 판정하지 않습니다. 새 학번 구간은 `src/checker.js`의 `CHECKER_GROUPS`에 같은 형식으로 추가하세요.
- 판정 시 가정한 부분(PDF 표만으로는 불분명)
  - 2022~2026학번 교과 25점은 캡스톤디자인·산학캡스톤디자인·전공영어기초·전공영어응용·예비창업설계 5과목(각 5점)으로 계산했습니다.
  - 비교과 미지정(자율활동)에는 TOPCIT 응시(회당 1점), 학과활동(회당 1점), 학과 MT(회당 2점, 지정 항목에 없는 학번), 직접 입력 점수(맛있는SW시리즈 등)를 반영합니다. 실제 인정 범위는 비교과센터에서 확인하세요.
  - 2016~2018학번은 PDF에 대학공통 표가 없어 2019~2022학번 기준을 준용합니다.
  - 다른 학과: 비교과 미지정(자율활동)은 맛있는SW·토익·정보처리기사 등 인정 항목이 다양해 **점수를 직접 입력**하게 했습니다(학과별 상한은 PDF 구간 점수).
  - 메타버스&게임학과 TOPCIT(5점)은 수준별·응시횟수별 환산 규칙이 복잡해 **환산한 인정 점수(0~5)를 직접 입력**하게 했습니다.
  - 정보보호학과 2016~2021학번의 전공영어 대체과목 규정, 사물인터넷학과 어학점수·자격증 세부 점수는 자동 반영하지 않았습니다.
- 이 도구는 **참고용**입니다. 최종 확인은 차세대 종합정보시스템(<https://st.sch.ac.kr>) → 학부학사행정 → 졸업 → 개인별졸업진도관리, 또는 多Dream비교과센터(향설 1관 RC306호)에서 하세요.
